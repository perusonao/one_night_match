## 1. 連続攻撃ダメージの即時適用か一括適用か

- 関連章: 仕様書 7.3
- 候補: (a) 即時適用（技成立のたびにHP減算） / (b) 一括適用（連続攻撃終了時にまとめて減算）
- 参考: 現行 `energy` モードの `_land()` は即時適用方式。整合性の観点では(a)が
  有力だが、正式決定はしない。
- 解決が必要なPhase: Phase 5

## 2. 複数のフォール・ギブアップ効果が同一連続攻撃中に成立した場合の処理

- 関連章: 仕様書 7章
- 候補: 未提示（要検討）。最初に成立した効果のみ有効とする案、両方を順に処理する案、
  後から成立した効果で上書きする案などが考えられる。
- 解決が必要なPhase: Phase 6

## 3. HP0時の行動制限

- 関連章: 仕様書 14章
- 候補:
  1. 通常どおり行動可能
  2. 休息しか選べない
  3. 低コスト技のみ使用可能
  4. 返技不可
  5. 自分のターン開始時に強制休息
- 解決が必要なPhase: Phase 3（最小実装／フラグ制で暫定対応し、Phase 6〜7で
  フォール・ギブアップとの相互作用を見て正式決定する）

## 4. 捨て札も空の状態で山札切れした場合の処理

- 関連章: 仕様書 13章
- 候補: 未提示。疲労状態への移行、行動不能ターンとして処理、などが考えられる。
  ただし新モードでは山札切れによる疲労ダメージ自体を採用しない方針（13章）のため、
  「手詰まり」状態の扱いとして別途検討が必要。
- 解決が必要なPhase: Phase 4〜5

## 5. 通常技・固有技・防御カードの同名上限

- 関連章: 仕様書 4章
- 候補: 未提示。フィニッシャー（最大3枚・同名不可）と同様の枚数制限を課すか、
  通常技のみ多投可能とするかなど。
- 解決が必要なPhase: Phase 2

## 6. 特殊キックアウトカードと通常キックアウトカードの区分

## 7. ギブアップ時のHP消費方式

- 関連章: 仕様書 10章

## 10. エスケープカードとリバーサルカードの違い

- 関連章: 仕様書 8.2章
- 候補: 未提示。両者ともフィニッシャー発動キャンセルに使える点は共通だが、

  未検討。
- 解決が必要なPhase: Phase 7

## 11. HEATの上限と、新モードでの役割

- 関連章: 仕様書 全般（HEATは現行 `energy` モードでレベル解放条件・フィニッシャー
  発動条件・スコアリングに使われる共有リソース）
- 候補: 未提示。上限を設けるか無制限とするか、新モードでのHEATの用途
  （レベル解放条件のみか、フィニッシャー発動条件にも使うか）を検討する必要がある。
- 解決が必要なPhase: Phase 1（データモデル）〜Phase 7（フィニッシャー発動条件）
